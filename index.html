第一章　通用上手流程：五步法

不管哪个平台哪款软件，流程都是这五步，差别只是按钮名字不同：

  1. 拿订阅：登录服务商后台，复制订阅链接；自建用户准备好配置链接。
  2. 装软件：从第二章列出的官方渠道下载安装，避开来路不明的安装包。
  3. 导订阅：找到"添加配置 / 导入订阅 / 新建配置"入口（一般在首页的 ＋ 号），粘贴链接保存。格式对不上时回顾 3.5 节的订阅转换。
  4. 选节点：一键测延迟，选数字小的（200ms 内为佳）。图省事可选"自动选择"。
  5. 开连接：打开总开关（手机端首次需允许 VPN 权限），打开系统代理或 TUN。访问一个平时打不开的网站验证，首页流量数字开始跳动即为成功。

日常维护三件事：订阅会自动更新，不用管；软件有新版本就升级；某个节点突然慢了，先换节点，再更新订阅，最后重启软件——九成问题止步于此。

第二章　分平台软件推荐与配置步骤

维护状态说明：以下"活跃"指 2026 年仍在正常发版更新。Clash for Windows、原版 Clash Verge、NekoRay、SagerNet 等老牌工具已停止维护，新用户不建议再用。

2.1 Android 安卓

首选：Karing

免费开源，基于 sing-box 内核，Flutter 界面，原生中文。最大优势是"来者不拒"：Clash、V2Ray、sing-box、Shadowsocks 等订阅格式都能直接导入，多种订阅混用的用户尤其省心。五端通用（Android/iOS/Windows/macOS/Linux）。

配置步骤：

  1. 从 GitHub Releases 下载 APK 安装（arm64-v8a 版适用绝大多数手机）。
  2. 首次打开同意条款、选择简体中文。
  3. 首页点 ＋ → 添加配置链接 → 粘贴订阅链接 → 确认。
  4. 点中央大按钮连接（首次需允许 VPN 权限），底部节点栏可测速换节点。

⚠️ NekoBox 的 Google Play 版本自 2024 年 5 月起由第三方控制，请只从 GitHub Releases 下载。所有安卓软件同理：认准官方 GitHub，拒绝第三方下载站和"内置节点版"。

💡 国产手机（小米、华为等）后台管控较严，装好后建议：允许自启动、电池策略设为"不受限制"、最近任务里加锁，可大幅减少锁屏断流。

2.2 Windows 电脑

首选：Clash Verge（社区版 Clash Verge Rev）

原版 Clash Verge 已停止更新，社区接续版 Clash Verge Rev 是目前 Windows 上综合体验最好的免费客户端：基于 Rust + Tauri 构建，内置 Mihomo 内核，界面精美，系统代理与 TUN 模式齐全，规则管理清晰。

配置步骤：

  1. 从 GitHub Releases 下载安装包，双击安装。
  2. 打开软件，左侧进 订阅 页 → 右上角 导入 → 粘贴订阅链接 → 确定。
  3. 点击该订阅使其生效，回 主页 选择配置和模式（规则）。
  4. 打开 系统代理 开关即可上网；需要全局接管时再开 TUN 模式（首次会要求安装服务/管理员授权）。
  5. 在 代理 页测速并选择节点。

2.3 iOS / iPadOS

iOS 上的代理软件都要付费或订阅（免费开源的 sing-box 除外），且中国大陆区 App Store 均无上架，需要一个非中国大陆地区的 Apple ID。

首推：Shadowrocket（小火箭）

美区售价 2.99 美元买断，是 iOS 上用户量最大、性价比最高的选择。支持协议全面（VLESS/Reality、Hysteria2、TUIC 等都支持），订阅格式兼容性好，社区教程丰富。

配置步骤：

  1. 用美区 Apple ID 登录 App Store，搜索 "Shadowrocket" 购买下载。
  2. 打开软件 → 首页右上角 ＋ → 类型 选 Subscribe → 粘贴订阅链接 → 保存。
  3. 回首页，在"全局路由"里选 配置（即规则分流）或代理。
  4. 打开顶部连接开关（首次允许 VPN 权限），在"服务器"页测速选节点。

第三章　基础概念：先懂词，再动手

代理软件的教程里全是行话，先把这几个词弄明白，后面看任何教程都不慌。

3.1 代理软件是干什么的

你的手机和电脑上网时，每个请求都要"出门"找到目标网站。代理软件做的事，是给这些请求安排一条你指定的路线：哪些请求走哪条路、走多快、走不走，都由你说了算。开发者访问 GitHub、运维人员管理境外服务器、普通用户改善某些网站的访问质量，都是它的常见用途。

3.2 内核与客户端（外壳）

这是新手最容易混淆的一对概念：

名称 是什么 例子
内核（Core） 真正干活的后台程序，负责转发流量、加解密、执行规则，一般没有界面 Mihomo（Clash.Meta）、sing-box、Xray
客户端（GUI） 你看得见、点得着的软件界面，负责管理内核 Clash Verge Rev、Karing、FlClash

同一颗内核可以套不同的外壳。"FlClash 和 Clash Verge Rev 用的是同一个内核（Mihomo）"就是这么来的——引擎一样，仪表盘不同。

3.3 机场

机场是圈内对"订阅服务商"的俗称，来源是一种调侃：把节点线路比作航线，买订阅就像买登机牌。服务商在多地部署服务器，用户付费后获得一条订阅链接，导入软件就能用这些线路。

需要提醒的是：机场行业鱼龙混杂，跑路、跑量、超售是常态，选购前多做功课；其提供的服务内容与方式是否合规，也请自行核实当地法规。这份文档不推荐任何具体机场。

3.4 订阅与订阅链接

订阅链接是一串以 http:// 或 https:// 开头的网址。软件拿到它，会自动下载一份线路清单——里面有服务器地址、端口、密码、协议等信息。服务商更新线路后，你只需在软件里点一下"更新"，或等着软件按设定间隔自动更新，不用重新配置。

把它理解成"一份会自动更新的通讯录"就对了。

3.5 订阅转换

有时你手里的订阅格式和软件对不上：比如服务商只给了 V2Ray 格式的链接，你的软件却只认 Clash 格式。订阅转换就是用工具把清单"翻译"成另一种格式。

常见的做法有两种：一是服务商后台直接提供多种格式链接（优先用这个）；二是用开源的 subconverter 类工具搭建或使用公共转换服务，把原始链接转成目标格式。

⚠️ 注意：公共转换服务能看到你的完整订阅内容（等于你的全部线路信息），敏感的订阅建议自建转换服务，或直接让服务商提供对应格式。

3.6 规则与分流

分流指"把不同流量指到不同出口"的安排方式。规则就是分流的具体依据，一般是一条条匹配条件，例如：

  • 访问 GitHub → 走代理节点
  • 访问国内网站 → 直接连接（不消耗订阅流量，速度不受影响）
  • 广告域名 → 拦截

大多数软件提供两种基本模式：

  • 规则模式（Rule）：按上面的规则表自动分配。日常使用选它，国内网站照常直连，两头都省心。
  • 全局模式（Global）：所有流量一律走节点。只适合临时调试，平时用会白白消耗流量、拖慢国内访问。

很多服务商或社区还提供现成的"规则集"，一键导入就有常用的分流方案，新手不必手写规则。

3.7 系统代理与 TUN 模式

这两种是流量"进入"软件的两扇门，互相独立，可单独也可同时开：

  • 系统代理：在系统网络设置里登记一个代理地址。浏览器等"配合"的软件会自觉走这条路；不配合的软件（部分游戏、命令行工具）则无视它。轻量省电，是电脑端的默认选择。
  • TUN 模式：软件在系统里创建一块虚拟网卡，接管几乎所有软件的网络请求，不挑软件。覆盖面全，但更耗资源，Windows 上通常需要管理员权限。需要代理游戏、或发现"某些软件不走代理"时再开它。

手机端连接本身就是系统级 VPN 方式，一般不用纠结这对概念。

3.8 延迟与测速

软件里的"延迟"（单位毫秒 ms）是你到节点服务器一个来回的耗时，数字越小响应越快。经验参考：200ms 以内流畅，300ms 以内日常够用，800ms 以上基本卡顿。测速只反映"你到节点"这一段，真实体验还取决于节点到目标网站的线路质量。

3.9 常见协议名速览

协议是客户端和服务器之间约定的"说话方式"，两端必须一致。新手只需混个脸熟：

协议 一句话说明
Shadowsocks (SS) 老牌轻量协议，用户基数大
VMess V2Ray 生态的老协议，VLESS 的前身
VLESS VMess 的轻量继任者，常与 TLS/Reality 搭配（详见第四章）
Trojan 把流量伪装成正常 HTTPS 访问
Hysteria2 基于 QUIC/UDP 的高速协议，抗丢包（详见第四章）
TUIC 同样基于 QUIC 的新一代协议
WireGuard 高性能 VPN 协议，也常被代理软件支持

第四章　协议介绍：Hysteria2 与 VLESS

这两个是 2024 年以来自建与机场线路中最常见的协议。理解它们各自的脾气，能帮你解释"为什么这条线快、那条线慢"。

4.1 VLESS：轻量、低调、客户端支持广

出身：VLESS 由 Xray 项目推出，接替 VMess。名字里的 "less" 就是"更少开销"的意思。

原理：VLESS 本身几乎不做加密，是一层很薄的信封——安全性完全交给外层的 TLS 负责收发时加密。这种"分层"设计带来了两个经典组合：

  • VLESS + XTLS-Vision：对"TLS 里再套 TLS"的流量做特殊处理，消除套娃留下的指纹，让流量看起来和普通 HTTPS 网页访问一样。
  • VLESS + Reality：客户端握手时"借用"一个真实大网站（如微软官网）的 TLS 证书，服务器主动探测时看到的就是那个真网站。架设者不需要自己的域名和证书，抗探测能力强。

特点：开销小、配置简单；Reality 组合抗封锁表现好；所有主流客户端都支持。

适用场景：需要长期稳定、兼容性好的网页访问；自建服务器时不想额外申请域名证书。是目前覆盖面最广的选择之一。

4.2 Hysteria2：快、抗丢包、走 UDP

出身：Hysteria 由 apernet 团队开源，第二代（Hysteria2）于 2023 年发布，目前是最热门的 QUIC 系协议之一。

原理：它架在 QUIC（HTTP/3 的底层，走 UDP）之上，有两处独门设计：

  • Brutal 拥塞控制：传统协议遇丢包会自觉减速，越丢越慢；Hysteria2 可以按你申报的带宽"顶格发车"，在 20%、30% 的高丢包线路上依然维持速度。
  • 伪装成 HTTP/3：流量外观与正常的 QUIC 网页访问一致。

特点：高丢包、高延迟的跨境线路上速度优势明显；缺点是走 UDP，部分运营商网络对 UDP 限速或拦截，遇到这种网络它反而连不上。

适用场景：线路质量差、丢包率高的网络环境；对速度敏感的传输任务；游戏加速（UDP 原生）。

4.3 两者怎么选

对比项 VLESS (+Reality) Hysteria2
传输层 TCP UDP (QUIC)
强项 稳定、抗探测、兼容性最广 高丢包线路下速度快、延迟表现好
弱项 极端丢包线路提速有限 UDP 被限速/封锁时失效
典型场景 日常长期使用 网络环境差、追速度、游戏

给新手的话：协议是服务端定的，你选不了"改协议"，只能选"支持该协议的客户端"。好消息是第二章推荐的软件全部同时支持这两种协议，照着选就行。

第五章　常见问题速查

现象 大概率原因 处理
添加订阅报 404/403 链接失效、输错，或被服务商拒绝 重新完整复制链接；无效就找服务商
添加订阅报"连接被重置" 订阅地址被网络拦截 先连上另一个可用代理再更新订阅

部分软件不走代理 只开了系统代理 电脑端开 TUN 模式接管全局

测速全是超时 订阅过期或节点全挂 更新订阅；仍不行联系服务商

第六章　合规与安全提示

安全合规说明（面向中国大陆用户）

因工作或学习需要访问国际互联网时，请务必遵守以下要求：

一、严格遵守当地法律法规，不访问政治敏感、邪教等违法违规网站，不下载、传播违法有害信息；

二、不在境外社交平台发布不当言论，不参与任何违法违规活动；

三、注册境外网站账号时，不填写任何真实个人资料（姓名、住址、证件号码等），并尽量避免使用国内手机号注册，防止个人信息泄露与关联。

  1. 工具中立，责任在人：这份文档介绍的均为公开的开源或商业软件。请确保使用场景符合所在地区法律法规，不用于任何违法用途。
  2. 不建议在校园网使用：高校校园网普遍部署了流量识别系统。使用代理软件时，学校无法看到你访问的具体网站内容，但能够通过流量特征识别出 VPN/代理连接——加密隧道的握手模式、长时间的大流量连接，这些特征都藏不住。一旦被识别，可能违反学校网络管理规定，面临通报、约谈甚至违纪处分。确有访问国际学术资源的正当需求，请通过学校提供的正规渠道申请。
  3. 只从官方渠道下载：这类软件的"高仿包、内嵌后门包"非常泛滥，认准 GitHub 官方仓库与官方商店，安装前留意下载量与更新时间。
  4. 订阅信息就是线路钥匙：订阅链接泄露等于把服务器拱手让人，不要发群里、不要贴到公共转换服务（见 3.5 节）。
  5. 先想清楚再付费：机场跑路常见，月付试水优于年付豪掷；iOS 付费软件认准开发者官方页面标价。
